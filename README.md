# 学搭子 · Demo 1.0

> 长视频自学场景下的 AI 伴学陪练（设计型项目 · Final Project Demo 1.0）
> **核心 Learning Goal**：学生能在**没有 AI 的情况下**把一条一小时以上的长视频独立学完学实
> ——自己把视频拆成学习单元、每学完一段先自我解释、再用自测定位薄弱点，一周后仍能提取并迁移。

## 怎么体验（不需要安装、不需要密钥）

下载本仓库中的 `index.html`，**双击用浏览器打开**即可。
这是一个自包含单文件页面，AI 的语言由内置规则引擎实时生成，任何人打开就能跑完整流程。

**90 秒走完一轮**（课堂演示脚本）：

1. 点"▶ 播放（模拟 8×）"看一段讲解，或直接点"看完了，进入『我先说』"
2. 在输入框里写下你自己的理解 → AI **判读**（长度 / 与原文重合率 / 是否有因果表述），并据此决定介入方式
   - 写太短 → 给思考框架（仍**不给答案**）
   - 粘贴原文 → 判为复述，要求换自己的话说
   - 说清楚 → 只确认，直接进小测
3. 做 2 题检索小测 → AI **只报对错与时间戳，不解释**；错题进回顾清单
4. 点"⚡ 我被打断了（模拟消息）" → AI 留下一条**未闭合的回路**（未答完的题 + 进度）
5. 点"↩ 我回来了" → 先做**两题冷启动**（1 题上段回顾 + 1 题上次没答完的）；按钮可跳过，跳过会被记录
6. 走到最后看**学习报告**：过程指标与结果指标分开；右下角可导出 JSON 埋点日志

页面底部实时显示**支持档位**：连续两段"先说清楚 + 小测全对"就降一档
（L3 给框架 → L2 只追问 → L1 只在求助时提示 → L0 只出题），这就是支持递减与最终撤出的原型。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | **Demo 本体**（自包含；片段与题目已内嵌，打开即用） |
| `template.html` | 页面模板，用 `/*__SEGMENTS__*/` 占位；换数据时重建用 |
| `bili_pipeline.py` | **数据管线**：B站视频真实字幕 → 学习片段 → 检索式小测题 |
| `segments.json` | 当前 Demo 使用的片段/题目数据（演示讲稿生成） |

## 用真实视频生成数据（字幕管线）

```bash
# 1) 演示讲稿（无需任何凭据）
uv run --with jieba python bili_pipeline.py --mock -o segments.json

# 2) 真实 B站视频：需要一个 Netscape 格式的 cookies.txt（登录态）
uv run --with jieba python bili_pipeline.py BV1xxxxxxxxx --cookies ~/某处/bili_cookies.txt -o segments.json

# 3) 把数据注入模板，生成可分享的单文件 Demo
python3 - <<'PY'
import json
tpl = open('template.html', encoding='utf-8').read()
d = json.load(open('segments.json', encoding='utf-8'))
open('index.html','w',encoding='utf-8').write(
    tpl.replace('/*__SEGMENTS__*/','window.SEGMENTS = '+json.dumps(d,ensure_ascii=False)+';'))
PY
```

**关于 cookie**：B站字幕接口在**未登录时返回空列表**（本机实测，`player/v2` 的
`subtitles == []`，看起来像"这视频没字幕"）。cookie 等同账号凭据，本项目约定：
只从本地文件读取、只发给 `*.bilibili.com`、不打印、不写入输出、不发送给任何第三方（含 ASR/LLM）。
无字幕视频的兜底是本机 ASR（音频同样不外传）。

## 已知局限（第一次真实运行后发现的，正在改）

1. **自动出题需要人工过一遍**：正则切法会把整个从句当术语（挖出"个很小的增量"这种碎片）；
   换 jieba 分词后仍有"法则""曲线"这类弱答案。题库质量直接影响测量效度，必须留人工校验环节。
2. **"因果表述"检测会被原文污染**：粘贴原文时也判出"因果 有"（原文含"如果……就"），
   所以现在把"与原文重合率"作为优先判据。
3. **判读不校验"说的对不对"**（第一次连续跑时发现）：同一段解释复制到第 2、3 段，判读仍给"清楚"——
   它只看长度、重合率、因果词，不看内容是否真的对得上这一段。真实版本必须加"与本段关键词覆盖率"
   或 LLM 判读，否则这个环节会奖励"会说套话"的学生。
4. **支持递减太快**：连续跑 3 段就 L3 → L0（第 4 段直接不给"先说一遍"的机会）。
   真实实验里应要求"连续两段 + 跨视频"才降一档，否则支持撤得比学生能力增长更快。
5. **跳过是流程的第一个死穴**（已修）：最初跳过后不推进题号，学生一跳过整条流程就卡死。
   真实数据里跳过率不会低，设计上必须"允许跳过 + 流程绝不中断"。
6. **当堂反馈会被下一段冲掉**（已修）：答完最后一题直接进下一段，学生看不到反馈与错题；
   现在改为先出"段小结 + 错题清单"再进下一段。
7. **Demo 用的是演示讲稿**（非真实视频），以保证任何人打开就能体验；真实视频字幕由
   `bili_pipeline.py` 生成，格式完全一致。
8. 时间轴为模拟播放（8×），真实版本会嵌入 B站播放器并按字幕时间戳同步。
